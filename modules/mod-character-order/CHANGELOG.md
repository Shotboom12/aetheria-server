\# Changelog



All notable changes to this project will be documented in this file.



\## \[1.0.0] - 2026-07-18



\### Added



\- Added the `.charorder` player command.

\- Added an account-character gossip interface.

\- Added character position, name, level, race, and class information.

\- Added move up, move down, move to top, and move to bottom actions.

\- Added immediate menu refreshes after reordering.

\- Added persistent character-selection ordering.

\- Added account-ownership validation for every selection and database update.

\- Added synchronous transactional database updates.

\- Added automatic exclusion of deleted characters.
